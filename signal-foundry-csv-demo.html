Convert a Website Contact Scraper or Greenhouse Jobs Scraper dataset to CSV in your browser. Save this HTML file and open it locally; Python and an Apify account are unnecessary for conversion.

Local processing · no API calls · no uploads

1. Choose your dataset

A JSON array of records, up to 2 MiB and 10,000 rows. Files are read in this page; their contents are not sent to a server.

This filter only changes this CSV. It cannot change charges from the original Actor run, verify mailboxes or grant permission to send messages.

2. Review and download

Choose your JSON file or try a synthetic sample.

CSV is UTF-8 with a BOM, quoted cells and Windows line endings. Arrays become semicolon-separated cells. Formula-like values receive a leading apostrophe, including phone numbers beginning with +. Keep the original JSON for unmodified values.

About this example. The bundled samples use example.com and are synthetic, not collected leads or current vacancies. The preview shows at most six rows and shortens long cells; the downloaded CSV contains the full selected records.

Signal Foundry publishes the optional paid Apify Actors referenced by the source and setup guide. This demo and the clients were created with AI assistance. Reading or using this file starts no paid run.
